# Change Accessibility Settings on a Chromebook

This guide explains how to find and change accessibility settings on a Chromebook.

It is intended for Chromebook users who want to customize their device to meet their needs.

## Before you begin

- Make sure your Chromebook is turned on.
- Sign in to your Chromebook if required.

## Open Accessibility Settings

> **Important:** The location or wording of settings may vary depending on the ChromeOS version.

1. Select the **Launcher** in the lower-left corner of the screen.
2. Select **Settings**.
3. Select **Accessibility**.

> **Tip:** You can also search for **Accessibility** in the **Launcher** search field to find these settings.

### Change text display size

> **Tip:** Open emails, documents, and web pages to see the results of your changes.

You can change the text size across your Chromebook's built-in display or change the font size in the web browser only.

To change the built-in text display size:
1. From the **Accessibility** settings, select **Display and magnification**.
2. Select **Display settings**.
3. Under **Built-in display**, select and drag the **Display and text size** slider.

To change the web browser settings only:
1. From the **Accessibility** settings, select **Display and magnification**.
2. Select **Website text and font**. The **Appearance** settings open in a new browser tab.
3. You have the following options:
   - For a quick test, select **Very small**, **Small**, **Medium**, **Large**, or **Very large** from the **Font size** dropdown options.
   - To choose a specific font size, select **Customize fonts**, then adjust the **Font size** slider.
